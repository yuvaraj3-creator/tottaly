# Tottaly — Complete Starter
A mobile-responsive Next.js price comparison platform.

## Included
Home, Products, Product Details, Categories, Deals, Compare, Search, Alerts, About, Contact, Privacy, Admin and Store pages.
Supabase schema, affiliate click endpoint and hourly Vercel Cron sync endpoint are included.

## Important
Live retailer pricing requires approved partner APIs/feeds and credentials. No unauthorized scraping is included. Replace the demo product data and `example.com` destination with approved partner integrations before launch.

## Run
npm install
npm run dev

## Deploy
Push to GitHub, import the repository into Vercel, add `.env` values, deploy, then connect your `tottaly.co` domain.
